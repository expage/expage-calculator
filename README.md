# expage-calculator

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23351693.svg)](https://doi.org/10.5281/zenodo.23351693)

Cosmogenic nuclide (<sup>10</sup>Be, <sup>26</sup>Al, <sup>14</sup>C) calculator for exposure age, erosion rate, burial duration, depth profile, glacial erosion, and production rate calibration.

Older versions: https://expage.github.io/calculator
